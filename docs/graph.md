# 图谱使用与链接规则

自动图谱根据知识库中 Markdown 笔记的引用建立关系，手动图谱保存为 `.graph` 文件。两者用途不同：自动图谱随笔记索引更新，手动图谱用于自行整理节点与关系；自动图谱快照会创建独立的手动图谱。

## 引用如何形成连线

- 支持 `[[笔记]]`、`[[目录/笔记]]`、别名、笔记嵌入和普通 Markdown 内链（包括引用式链接）。标题和块引用按所属笔记连接。
- `./`、`../` 相对于引用所在笔记；以 `/` 开头的路径相对于知识库根目录。路径中的 URL 编码只解码一次。
- 同名笔记优先匹配当前目录；仍有多个候选时不任意选择，也不将歧义目标当作未创建笔记。
- 外部网址、图片和其它附件不作为笔记关系。代码块、行内代码、HTML 注释里的示例不形成连线。
- 自动图谱重复引用合并为同一关系；同页引用不画自环。

解析规则升级后旧索引缓存会重新建立，不会修改笔记内容。

## 浏览与编辑

自动图谱可显示或隐藏孤立笔记、未创建笔记。搜索定位用于寻找节点，全图适配用于恢复可见范围；局部关系图以当前笔记为中心，查看指定层数内的邻接笔记。

手动图谱在编辑模式下添加节点、连接节点、重命名与绑定笔记。编辑时点击节点用于选择，浏览时可以打开绑定的笔记。快照与手动编辑的结果保存在知识库中；AI 生成功能需先配置可用的模型服务。

当前不提供标签着色分组、边的关系类型或方向编辑。
