# 本地知识库分享

在笔记的「更多」菜单中，选择「导出 PDF」下方的「分享」。也可在编辑器中按 Windows `Ctrl+F5` / macOS `⌘+Shift+F5` 打开分享弹窗；Mac 功能键被系统占用时需同时按 `Fn`。快捷键只打开弹窗，不会自动启动分享服务。

- 端口默认 80，可改为 1–65535 的整数。端口占用或权限不足时，可使用 8080 等其他端口。
- 密码留空时无需登录。设置密码后，访客在登录页只需输入分享密码，无需账号；重启分享服务后需重新登录。
- 点击「启动分享」后，复制弹窗中的局域网地址给同一网络中的设备。localhost 地址仅限本机使用。访问失败时检查两台设备是否在同一网络，以及系统防火墙是否允许 EasyMD 入站访问。
- 首页显示统计与目录；目录覆盖当前知识库中的普通文件和文件夹。隐藏目录、符号链接与 node_modules 不对外提供。
- Markdown 可在线阅读，图片可预览，画布文件不会出现在分享目录或导出的 ZIP 中；其他附件可下载。支持居中容器与 `<img>` 图片标签（src、alt、title、width、height），其他原始 HTML 仍按文本显示。
- 分享只读，不支持远程修改。内容来自已保存的磁盘文件；未保存的编辑不出现在分享页面。
- 分享页工具栏的「阅读模式」会隐藏左侧统计与目录、展开文章区域；再次点击「退出阅读」可恢复。手机端会自动将目录收起到上方区域，并适配窄屏阅读、代码块和工具栏。
- 分享弹窗底部的「导出部署包」会生成自包含 ZIP（含 `index.html`、静态脚本、样式、目录和知识库文件），解压后可直接作为 NGINX 静态站点目录部署。导出不包含隐藏目录、符号链接或 `node_modules`。
- 分享弹窗提供局域网地址二维码，同一网络的手机可扫码打开；多个网卡地址可切换。二维码不包含访问密码。
- 地址旁的「打开」调用系统默认浏览器。软件预览与分享页的代码块显示语言（未声明时显示 text），右上角的复制图标可复制代码。
- 分享固定为启动时的知识库。切换知识库不会自动改变分享范围，需要停止后重新启动。
- 关闭弹窗不会停止服务；点击「停止分享」或退出 EasyMD 停止服务。下次启动应用不会自动开启分享。

本服务使用 HTTP，密码保护不提供传输加密，适合可信局域网。不需要公网服务或 CDN。
